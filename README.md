## 프로젝트 개요
HANA + ASSET은 사용자 자산 정보를 바탕으로 서울시 전월세 매물을 분석하여 적합한 대출 상품을 추천하고,  
하나은행의 전문 대출 상담사와 실시간 상담을 통해 전월세 자금 대출 계획을 효율적으로 수립할 수 있는 플랫폼입니다.
